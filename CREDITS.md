# Credits

## LMASTER Mod

**Pyra Drake**, [Nexxus Drako Multimedia](https://github.com/NexxusDrakoMultimedia):
mod design, reverse engineering, in-game testing, release.

Every change in the mod comes from the
[LMAST-Reverse](https://github.com/NexxusDrakoMultimedia/LMAST-Reverse)
project, which documents how the game works and builds the patches. Its
`DOC/LMASTER_MOD.md` holds the evidence and test results for each
change. The reverse engineering was done with Claude (Anthropic).

The widescreen patches are LMAST-Reverse's
`PNACH/SLES-54151_3CB245D5.pnach`, renamed for each edition.

Real logos and texture fixes are a separate project,
[LMAST-Realism](https://github.com/NexxusDrakoMultimedia/LMAST-Realism).

## Thanks
